# Market landscape

People already have many ways to see the periodic table. Few of them are a single instrument that teaches the element at more than one depth, compares a neighbor honestly, and puts the spectrum in the same product on a phone and on a classroom screen.

## Adjacent products

| Product | What it does well | What Element Deck still has to earn |
| --- | --- | --- |
| [Ptable](https://ptable.com/) | A dense, loved interactive table in the browser; properties, orbitals, trends | Desktop-web first. Not a phone app with a dossier, a curated congener lesson, and a settings model |
| [Royal Society of Chemistry periodic table](https://www.rsc.org/periodic-table) | Authoritative, classroom-trusted articles and a clear table | Article-shaped. Depth is "read more," not a mode. Weak as a pocket comparison tool |
| [IUPAC](https://iupac.org/) data and the periodic table project | Names, weights, the standard | A standards body, not a learning UI |
| [NIST Atomic Spectra Database](https://physics.nist.gov/PhysRefData/ASD/lines_form.html) | The line list Spectra must respect | A query form for specialists. Not a glow, a tone, and a school explanation |
| [WebElements](https://www.webelements.com/) | Long-standing per-element facts | Pages, not a depth-aware shell |
| Wikipedia element articles | Coverage of all 118 | Inconsistent depth, no comparison bench, no themeable app shell |
| Store "periodic table" apps | Offline grids, quizzes, flashcards | Most stop at the poster plus a short card. Quizzes without the instrument |
| [PhET](https://phet.colorado.edu/) and similar sims | Excellent focused interactives (build an atom, states of matter) | Each sim is a topic. None is the whole table as a daily reference |
| Textbook publisher apps | Aligned to a syllabus | Closed content, little spectra, little cross-platform craft |

## The gap

```text
        POSTER APPS              REFERENCE SITES
        symbol grid              long articles
                \                  /
                 \                /
                  Element Deck
                  one element
                  three depths
                  compare + spectra
                  phone and desk
                 /                \
                /                  \
        CLASSROOM DISPLAY     POCKET LOOKUP
```

Ptable proves people want a beautiful interactive table. NIST proves the lines exist. School apps prove students will install a table before an exam. The opening is the product that connects those without turning into a wiki or a quiz skin.

Element Deck's specific bets:

- **Depth is a control**, not a longer page.
- **Compare is a room**, with computed deltas and a few written lessons.
- **Spectra is a room**, cited, sonified honestly, with isotopes beside the light.
- **The shell is finished-app quality**: theming, settings, wide layout, and help.
- **The catalog is a content pack in Firebase**, cached on the device after purchase, so a correction does not wait on an app-store release.
- **Who bought which package** is a Firestore record checked against the store receipt.

## What not to chase

- Beating NIST as a spectroscopy authority. Cite it.
- Beating Ptable on decade-deep trend plots in v1. A single ionization sparkline and a real compare room are enough to start.
- Beating quiz apps on streaks. Out of scope.
- A chatbot that paraphrases the dossier. The dossier is the product.
