# Educator

**Persona:** Educator  
**Depth default:** Intermediate  
**Shell:** wide, when the room has a tablet or a browser. Phone still works for preparation.

An educator uses the same app the students have. There is no presenter build.

## Job

Home asks: *Which element is in front of the class, and can someone change depth without leaving?*

Success: the back row can read the symbol, the family, and the sentence that matters today. A student who is lost can drop to Beginner on their own phone. A student who is bored can open Advanced.

## Preparation

On a phone, the night before:

- Search the element.
- Read the three curriculum blocks. Decide which depth to open with.
- Run Compare against the neighbor the chapter uses. Export the PDF if the school wants a handout.
- Check Spectra if the lesson mentions color or isotopes. Decide whether sound stays on.

## In the room

Wide shell on a tablet or a projected browser:

- Rail on Table or Details.
- Depth control in the left column, where it can be changed without scrolling the dossier away.
- Chalk theme if the projector washes out Obsidian Orbit. Family colors stay.
- Reduced motion and sonification off if the room needs quiet. Both are App settings, reached from the rail.

Students follow on `/e/22` (or whatever Z). Their depth is their own unless a class assignment later suggests one. Suggestion is not a lock.

## What the educator is not asked to do

- Maintain a private copy of the facts.
- Build slides from screenshots, unless they want the PDF.
- Create accounts for students. Everyone installs the same static app. A class list, if it comes later, waits on terms before any minor is invited.

Each learner buys the course pack they need. There is no separate Classroom product in this build.
