# Details

![Details](asset:assets/help/images/details.png)

Callouts: **identity header** · **bookmark** · **Details, Data, History, Trivia**.

## Purpose

Details is the dossier for the current element. It opens from a table cell, a registry card, or the **Details** tab. If you have not chosen an element yet, the dossier uses the element already selected for the session.

The header line reads **PERIODIC EXPLORER · DETAILS**.

## Identity header

The header stays pinned while the page scrolls.

- A short isotope line, when the pack has isotopes for this element.
- The symbol, in the family color, with atomic number and name.
- Atomic weight and whether that weight is a standard atomic weight or a representative isotope.
- Category, block, period, and group.
- **Bookmark**. A filled bookmark means this element is saved on this device. Tap it again to remove the bookmark.

An element that is not in the on-device catalog shows its name and the note **In the full pack**.

## Details tab

The first tab is a reading page for this element:

- A short summary.
- A shell diagram of the electrons. **Reduced motion** in App Config turns off extra motion in that diagram.
- **Uses**, when the pack has them. Each row is one use, with a short explanation.
- **Simulate Reaction**, when a known reaction is curated. It opens an illustration: reactants, products, conditions, and a teaching note. It is an illustration of a published reaction, not a lab procedure to run.

## Data tab

**Data** lists compiled values in labeled groups: identity, electrons, physical properties, isotopes, and spectrum.

Units follow **App Config**. A temperature can display in °C while the stored value stays in kelvin. The same is true for energy and length.

Labels with a dotted underline open a reference article for that property: what it measures and where the unit comes from. The article is about the property, not a second measurement of this element.

Missing values say **Not reported**. They are not filled in with a guess.

## History tab

**History** is a narrative for this element, plus a discovery card when the pack has a year, the people, and a short genesis note. If the pack has no history yet, the page says so.

## Trivia tab

**Trivia** lists short stories. Tap a card to read the full story. If this element has no trivia in the pack, the page says so.

## Try this

1. Open carbon from Table, then switch **Details**, **Data**, **History**, and **Trivia**.
2. On **Data**, tap **Electronegativity** and read the property article. Back returns to the dossier.
3. Bookmark the element and confirm the icon fills.
4. If **Simulate Reaction** is shown, open it, read the equation, and dismiss the sheet.
