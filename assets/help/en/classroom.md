# Classroom

![Classroom](asset:assets/help/images/classroom.png)

Callouts: **class name** · **join code** · **pinned elements**.

## Purpose

Classroom is a shared list for a class: a name, a join code, a suggested learning depth, and a few pinned elements. Open it from **Settings**.

It is not a second app and not a different navigation. Each learner still uses Element Deck. The class record says which elements the group is looking at.

## Before a class exists

If the Classroom package is not on this account, the page says to buy Classroom after Element Deck. Join codes meant for minors wait on terms. The preview rooms still work.

## Create

Type a **Class name**. **Create class** stores a class with a suggested depth and a starter set of pinned atomic numbers.

When a class is current, the page shows its name, its join code, the suggested depth, and the pinned atomic numbers.

## Join

Type a **Join code** and tap **Join**. A failed code is reported on the page.

**Show all elements** leaves the class view so the full catalog is visible again.

## Try this

1. Read the package line at the top so you know whether Classroom is active.
2. If you are only exploring, do not create a class on a shared device.
3. If a class is already current, note the join code before you leave the page.
